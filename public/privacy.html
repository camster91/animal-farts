💨 PootBox Privacy

Current notice

Last updated August 28, 2026. PootBox v1 is a sound toy with private, code-based sharing. Public profiles, discovery, follows, feeds, comments, reactions, and public recording lists are turned off.

No account needed

We don't ask for an email address or account. The app creates a random identifier in this browser so the server can recognize which recordings this device may delete. Clearing browser data removes the local identifier and may prevent the app from proving ownership of an earlier upload.

What stays on the device

Pages, settings, recording names, and local recording copies are stored in browser storage. They can be removed with the app's controls or by clearing this site's browser data.

Microphone and uploads

The microphone is used only after you start a recording, never in the background. When the app is online, a completed recording is uploaded to the PootBox server so it can survive a reload and be shared. The server stores the audio file, its name and emoji, the random device identifier, and timestamps. A device may store up to 40 server recordings.

Sharing and deletion

Sharing creates an eight-character code that expires after 30 days. Anyone who has a valid code can play that recording, so a grown-up should help choose recipients. Deleting a recording stores a deletion request on the device before removing the card, then removes the server metadata, audio, and share codes. If offline, the request retries after reconnecting and the app shows whether it is waiting or needs help. Clearing browser data before queued work finishes can remove that pending request and does not by itself delete an existing server copy.

Operations and safety

The server rate-limits requests, validates uploaded audio, and filters blocked words. Error and feedback reports may write a sanitized message, stack, page URL, browser user agent, timestamp, and legacy profile identifier to operator logs. We do not intentionally log recorded audio or request bodies. Public social features remain unavailable until guardian controls, reporting, blocking, retention, deletion, and human abuse-response processes are defined and tested.

No ads, no analytics

The v1 app has no advertising or analytics SDK and we don't sell data. PootBox is made for kids and families.
